## ADDED Requirements

### Requirement: three real ideas walk the complete closed loop

Fuzzy (divergence-heavy), crisp (direct), doomed (make-or-break dies) — each through A1 intake → A0 confirmation → headless research walk → dual rendering → version commit → MCP verdict.

#### Scenario: fuzzy idea walks with divergence
- **WHEN** the fuzzy idea (7 utterances, 3 branches) walks the loop
- **THEN** the A1 router routes all utterances, the divergence check fires, and the idea commits with its verdict

#### Scenario: doomed idea walks with early termination
- **WHEN** the make-or-break refutes mid-research
- **THEN** the hard gate pauses, bury converges, and the NO-GO commit lands

#### Scenario: all three coexist in one ledger
- **WHEN** all three ideas freeze
- **THEN** three versions exist (one per task), the chain verifies, and MCP exposes all three verdicts
