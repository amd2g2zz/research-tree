# webui-chatgpt-ui

## Why

Issue #653 (user ruling 2026-11-03): 现有仪表盘式拼卡不是正式产品形态——**按 ChatGPT 的页面做**。ChatGPT 范式映射到 rt：左会话列表（项目/研究树）+ 居中对话主流 + 底部输入胶囊 + 右侧画布面板（分解/研究/版本如 ChatGPT canvas 从对话滑出）——恰好正是 docs 03 "hub 对话=项目主界面" 的产品设计。

## What changes

- `webui/src/App.tsx` 全量重写 + `styles.css` 全量重写（**服务端零改动**——既有 RPC/REST 全部复用）：
  - 左侧 260px 侧栏：新研究按钮、项目→任务列表（最近状态）、项目 ⋯ 菜单（归档/删除，红线 verbatim）、底部 pi 就绪状态点+设置入口。
  - 主列：顶栏（标题+相位+分解/研究/版本/演练按钮）；居中对话流（用户灰气泡右对齐、rt 回执左全宽带 ◉、无装饰卡）；底部输入胶囊贯穿所有阶段（kind 选择器收进胶囊）。
  - 右侧 460px 画布面板：分解（六格卡墙+溯源+checklist 门）/研究（图谱+确定性重放条+lineage 抽屉）/版本（时间线+继续研究+分叉），✕ 关回对话。
  - 模态：新研究、设置（pi 同源写路径不变）、只读快照（🔒横幅）。
- 视觉：ChatGPT 式极简白、系统字体、灰泡、细分隔线；红线保持——徽章带文字（已决/未决）、草稿"未冻结·不可跟踪"、已提交无修改入口。
