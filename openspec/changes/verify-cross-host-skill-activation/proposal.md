## Why

Discovery and a valid installation currently look successful even when a host turn never received the research-tree body. Host-native evidence is required so file links, stale targets, and unavailable executables cannot pass activation parity.

## What Changes

- Define discovered, static-ready, and live-verified evidence with bounded receipts.
- Add independent side-effect-free Codex, Claude Code, and Hermes probe contracts.
- Diagnose missing, current, legacy, stale-link, and conflicting installations without implicit rewrites.
- Reject malformed/file-link markers, wrong-host packages, digest drift, and unavailable hosts as live evidence.

## Capabilities

### New Capabilities
- `skill-activation-integrity`: host-specific activation evidence, receipts, diagnostics, and probe dispositions.

### Modified Capabilities
- None.

## Impact

Touches setup/activation tooling, package inputs, compatibility references, generated packages, group-32 evidence, and focused tests; it adds no dependency or lifecycle authority.
