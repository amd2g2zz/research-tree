## Why

Alpha2 currently has governed evaluation assets and focused runtime tests, but it does not yet have one executable release decision that separates non-negotiable integrity failures from quality diagnostics across equivalent public host inputs. Without that boundary, superficial proxies or self-reported host success can still be mistaken for release evidence.

## What Changes

- Add a versioned black-box release manifest with public case bindings, opaque hidden-oracle references, host execution dispositions, independent runner records, blinded review references, and retained limitations.
- Add deterministic integrity gates for zero false completion, resolvable P0 evidence and closure, recovery preservation, semantic delivery consistency, hidden-oracle isolation, and cross-host canonical parity.
- Add semantic quality diagnostics for intent fidelity, contradiction handling, depth, unsupported claims, implementation success, rediscovery burden, and professional usefulness without allowing those scores to waive an integrity gate.
- Persist an offline-verifiable release decision that records unavailable hosts honestly and never treats an LLM judge, source count, wave count, headings, or report length as sole release authority.

## Capabilities

### New Capabilities

- `black-box-release-gates`: Versioned cross-host release manifests, independent evaluation evidence, integrity gates, quality diagnostics, and deterministic release decisions.

### Modified Capabilities

- `research-quality-evaluation`: Replace proxy-only completion claims with explicit public case, hidden-oracle, independent runner, blinded review, recovery, parity, and release-decision requirements.

## Impact

- Adds a release-evaluation module and focused black-box/release-manifest tests.
- Adds governed evaluation schemas, public case fixtures, harness metadata, and retained release-result evidence under `evaluation/`.
- Updates Alpha2 task execution/verification registries and release evidence without changing runtime completion authority or exposing hidden oracle bodies.
