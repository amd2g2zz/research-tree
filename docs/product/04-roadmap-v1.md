# v1.0 路线图 — research-tree

版本 v2.3 · 2026-10-30 ·（v2.3：**宿主独占裁定——rt 只支持 pi agent**，codex/hermes/claude-code 等旧 harness 兼容全部移除（MCP 出口保留，它是产品接口而非 harness 兼容层）；v2.2：语言裁定——v2 引擎全量 TypeScript，rt-core 为引擎本体，Python v1 冻结为遗留参照；v2.0：git 语义纳入——T0 增六要素分解与版本/分叉存储，T1 增分解可视化与产物管理，T3 增版本时间线/分叉/主分支投影；v1.1 的递归阶段化/项目管理/画布保留）· 计划范式：**能力制里程碑（做完即达成，与日历无关）+ agent-时为规模单位（S=1-2h/M=2-6h/L=6-16h）+ 承诺半径=当前波次**。日期只作预测永不作承诺。

## 产品不变式（路线图遵守）

pi 是家且**pi 独占（v2.3：不兼容任何其它 harness；codex/hermes/claude-code 宿主面移除）**，MCP 是出口（rt.start/status/correct/verdict——接口，非兼容层）；**v2 引擎全量 TypeScript（2026-10-30 裁定）：rt-core 为引擎本体——存储/账本/算法/状态机/调度/headless/MCP 全部 TS；Python v1 冻结为遗留参照（行为语义与测试规格复用，代码不迁移），直至 v2.0 发版退役**；三种方法封顶（贝叶斯/Thompson/GEPA——阶段递归是它们在阶段粒度的实例，不是新方法）；研究 = 阶段 DAG 上的递归推断，全局预算硬帽 **12h/-run**；画布是 12h 无人值守的**信任面**（看不见的研究不可信）；**研究是一棵树（git 语义：草稿可变/提交不可变/分叉即继承/主分支默认投影）**；克制清单（无协作画布/无自研渲染/无流处理框架/无跨项目共享）。

## T1 单项目单闭环 + 最小画布 — P0（端到端真实研究）

| 交付 | 内容 | 验收 |

| 证据引擎简版 | 来源注册+可靠度点估计（加权投票）+独立性坍缩（引用链）+快验层 | 冲突来源正确降权实测 |
| A3 EVSI 三动作 | 读源/交叉/问用户（实验层后置 T2） | 动作选择可复盘（含次优差距） |
| 单席验证+反证配额 | 每压死性主张 ≥1 轮反证查找 | 引用抽检通过率 ≥95%（**H4 首测**） |
| **最小画布** | react-flow：**三层图谱（研究问题→主线任务→调研 DAG：阶段×主张）** + 节点抽屉（主张/证据/原始会话）+ console 尾流（随重放同步）+ 侧栏研究树（项目→任务→版本节点） | 画布=账本纯投影（同源投影测试）；写操作仅五门 |

| **分解可视化+产物管理** | 六要素卡片墙（溯源引用/删除合并）+ 确认启动 v0 + 收敛后产物删除/冻结提交 UI | 分解-确认-研究-删除-冻结全流程实测；deleted_nodes 随快照落库 |

**T1 退出**：2-3 个真实想法端到端全旅程 + H1/H3 首轮数据落袋。约 **12-16 agent-日**。
