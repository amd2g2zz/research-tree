# 核心算法规格 — research-tree v2.0

版本 v2.1 · 2026-10-28 · 总纲：**主张账本是心脏；一切裁决由机械规则在账本上计算。LLM 产生判断（提取/取证/叙事），判断落盘为数据后由算法统治。判断可漂移（换模型），账本与规则不动摇。** v2.0 新增：A0 六要素分解算法、A7 版本与分叉算法（git 语义）。

## A0 六要素分解算法（对话 → 研究任务，v2.0 新增）

**触发**：用户在 chat 中点确认（"聊得差不多了"）；前置门槛 = A1 收敛判定 converged。

**输出 schema（越充分越好，宁多勿漏）**：

```
Decomposition {
  requirements:   [要求]   # 用户要什么，可判定
  constraints:    [约束]   # 硬约束（部署事实）与猜测约束分列；来源=约束溯源
  background:     [背景]   # 任务背景，含附件解析产物（图片/文档/表格/PPT）
  intents:        [意图]   # 底层目标（为什么问这个），显性偏好>陈述偏好
  refusals:       [拒绝点] # 用户明确不要什么（non-goals、被否方案）
  difficulties:   [难点]   # 预判的验证难点，逐条映射到 kill 图候选承重主张
  claims_preview: [主张]   # 由六要素推导的账本预览 + kill 条件（用户签署）
}
```

**机械规则**：
1. **溯源律**：每条要素必须携带 source（chat 消息 id 或附件 id + 引文）；无法溯源的要素是幻觉，落盘前丢弃。
2. **充分性 checklist**：六类各 ≥1 条才算分解完成（拒绝点可以为空但必须显式确认"无拒绝点"）；难点 ≥1 条没有对应 kill 图承重主张 = 预注册缺口，阻止确认。
3. **分类是语义分类，不是用户分类**：同一条话术可拆到多个要素（"2C4G 越快上越好" = 约束 + 意图 + 背景）。
4. **编辑权在确认前**：用户可删除/合并/改写要素条目；确认后要素集随版本 v0 一起落盘（成为研究的宪法）。
5. **变更语义**：研究启动后要素变更 = kill 条件/范围变更 = 重大转向（重签）。

**与 A1 的关系**：A1 四分路由是逐句的在线路由；A0 是收敛后的批量结构化——路由的槽位/账本/假设/停车场内容是 A0 的输入，A0 补全交叉引用与 kill 图预映射。

## A7 版本与分叉算法（git 语义，v2.0 新增）

```
Version {
  task_id, v: u32,                    # 同一 task 内单调递增
  commit_hash: sha256(账本快照+要素集+报告+产物集),
  parent: (task_id, v) | None,        # None = 任务起点(v0)
  summary: str,                       # 自动生成的研究摘要消息
  verdict: GO|NO-GO|PARK|REFRAMED,
  deleted_nodes: [node_id],           # 冻结前用户删除的产物（可审计，不假装没删过）
}
ForkEdge { from: (task_id, v), to: new_task_id }   # 图谱一等公民，双向可查
```

**机械规则**：
1. **快照即提交**：commit_hash 对"要素集+账本+证据引用+报告+已删除节点清单"整体做内容寻址；部分提交不存在。
2. **草稿不可跟踪**：未冻结状态只有 draft（无 hash、不入图谱、不进版本线）；用户显式冻结才产生 Version。
3. **版本 +1 = 继承 + delta**：新 draft 从最新提交（或 fork 源）复制账本快照（copy-on-write），agent 基于已有研究重新对齐 → 补充研究 → 冻结 → v+1。不重跑已决主张（除非其前提在新证据下被重开）。
4. **分叉 = 新 task 继承**：fork(v) 生成新 task-id，其 v0 = 源版本快照的浅拷贝 + fork_edge；两个 task 各自独立生长，图谱记录血缘。
5. **展示规则**：项目页默认渲染主分支最新提交的投影；切换分支/版本 = 显式用户动作（URL/task-id 寻址）。
6. **不可变审计**：已提交版本不可修改；"纠正历史"= 提交新版本。deleted_nodes 随版本记录，报告披露"用户删除了哪些产物节点"。

**与画布的关系**：版本时间线 + 分叉边是画布的版本维度；任一结论 3 次点击溯源到原始证据的规则对每个历史版本同样成立（快照保留了各自的证据引用）。

## A1 缺口对话控制器

**每轮流水线**：分解（四分路由）→ 槽位更新 → 主张提取（schema 校验）→ 快验层（新主张×证据索引廉价比对，冲突当场标记）→ 收敛评估 → 下一步选择（追问/重述锚点/发散诊断/出研究计划）。

**四分路由（含需求解构 `demand_decompose` 与纠正同路由）**：

| 话语类型 | 路由 | 对待 |
|---|---|---|
| 偏好/意图 | 槽位（权威域） | 遵循到底 |
| 事实主张 | 主张账本 | 检验：不信不驳 |
| 方案猜测（含"内存 2M"类约束猜谜） | **假设账本** | 受理受审：登记为候选方案假设，与替代方案同台评审 |
| 分支/岔路 | 停车场 | 收纳不惩罚，不进关键路径 |

**约束溯源**：构成可行性边界的约束必问"是部署环境事实，还是您对'轻'的估计？"——猜测约束当场松绑为意图。**纠正无特权通道**：用户纠正按同一四分路由分解（偏好变更→照办+后果映射；私有事实→账本+私有证据 elicitation；猜测重申→假设账本重审）。

**收敛判定（计算属性，非 LLM 感觉）**：

```
converged ⟺ C1 问题成形度≥阈值(可判定∧有范围∧连着决策) ∧ C2 关键槽位非空
           ∧ C3 make-or-break 已识别≥1
软信号: C4 新主张率衰减(近2轮<早期×0.3) ∧ C5 重述未被纠正
```

**意图穿透的偏差防护**：高风险解构（改变 kill 条件∨可行域菜单∨底稿结构）强制回声确认；显性偏好>陈述偏好（从用户选择更新意图模型）；意图模型为可见版本化工件。**方向工件版本化**（意图/假设/kill 图各自版本化）：错误纠正只污染一个版本，diff 可见可回滚——方向像分支可 revert，知识像历史不重写。

**发散与兔子洞**：连续 2 轮分支>主张 → 上游检查提议地形对比；持续分支是"该换研究模式"的信号，不是噪音。

## A2 主张账本与 Kill 图

```
Claim { id, text(可判定), source: user|research,
        weight: make_or_break|important|minor,   # LLM 提议，计划确认时用户签署 kill 条件
        posterior: P(supported),                  # 后验，二值状态只是投影(≥0.9/≤0.1)
        evidence: [EvidenceRef],                  # 内容寻址 sha256，挂来源节点
        verify_tier: 重推导|多源交叉|原文摘录|单源未验|experiment,
        kill_edges: [claim_id], precondition_split: [version|scope] }
```

**Kill 图**：主张 AND 依赖 DAG；make-or-break = 高中心性无替代路径（图性质，非打分魔法）。用户签署 kill 条件 = 早终止合法性来源。**信念传播**：前提被驳 → 后代主张自动重开（append-only，靠重开翻案，不靠删除）。

## A3 统一 EVSI 动作选择（原 VOI 调度的推广）

对每条 uncertain 主张，候选动作={再读独立源 | 交叉核对 | re-derive | 问用户 | 跑实验 tier-k}，统一按 **EVSI/成本** 选择——"再读一篇论文还是跑五分钟 benchmark"是同一个公式算的。EVSI 值同时是喂给 loopx quota 路由的信息增益评分。make-or-break 恒优先（早杀省最多）。

## A4 分层验证执行

| 主张类型 | 方法 | 层级 |
|---|---|---|
| 经验可跑 | 最小判别实验（reproduce 脚本/微基准） | 最高 |
| 文献/事实 | 多源交叉 + 原文摘录锚定 | 高 |
| 逻辑/推导 | fresh-context 验证子代理盲重推导 | 高 |
| 市场/判断 | 证据三角化 ≥3 独立源 | 中 |
| 仅单源 | 诚实标记，**永不升级为 supported** | 低 |

**对抗搜索**：make-or-break 主张双席取证——原告代理只找反面（反例/失败/版本陷阱/前提失效），辩护代理只找正面，预算相等、EVSI 独立结算，**先攻后守**。完备性要求由 kill 图定义：**负载点穷尽、其余有界**；停止=EVSI 饱和（"停止学习"≠"世界查完"），报告披露搜索信封（查了什么/没查什么/没查到什么）。

## A5 早终止与变体搜索

```
after each 验证轮:
  if ∃ make_or_break: posterior ≤ 0.1 或持续恶化:
     variant = kill 图变体搜索: {放宽|替换|绕过}被驳主张 → DAG 仍立?
     PAUSE → 呈现证据 + "埋了 / 继续挖 / 换这个变体"   # 问句不是判决
```

早终止是 run-plan 硬门（fail-closed）：make-or-break 被驳则研究不得继续，除非用户显式选择。

## A6 裁决与双渲染

```
GO    ⟺ 所有 make_or_break posterior ≥ 阈值 ∧ important 支持率达标（阈值=用户风险参数）
NO-GO ⟺ ≥1 make_or_break 被驳 ∧ 无存活变体
PARK  ⟺ 预算/信息不足 ∧ 复活条件已写
REFRAME ⟺ 变体搜索产生显著更优问题（用户确认，带 delta 报告）
信心 = f(verify_tier 分布, 未决主张数, 反证搜索覆盖度, 搜索信封质量)  # 定性档位，禁止假百分比
```

**渲染是纯函数**：报告=叙事渲染（三元呈现：证据[无偏好]×偏好风险[用户签的]→建议）；底稿=结构渲染（supported→带证据链断言；asserted→显式风险登记）。同源投影，不可能互相矛盾。

## 贝叶斯证据引擎（A2-A4 的推理底座）

```
L1 来源层: 溯源图(origins.py 升格) + 独立性坍缩(引用链/内容指纹/时间模式→坍缩到独立根)
          + 来源可靠度后验(挣来的,不是假设的) + 激励向量(affiliate/赞助/持仓→先验下移)
          + 协同检测(astroturfing 签名: 同构论证/同步发布)
L2 推理层: 每主张 P(supported | 全部观测, 可靠度后验); 激励污染主张需更高层级证据;
          全污染源集封顶 contested
L3 决策层: A3 的 EVSI 统一选择
L4 实验层: 预注册(假设/判别判据/最小样本量/成本上限,先注册后执行) + 序贯停止(SPRT 式,
          后验过阈即停) + 阶梯硬门(T0 静态→T1 分钟级$→T2 小时级$$→超限=experiment-gated
          进风险登记,不跑) + 设计者不执行(fresh-context 独立子代理,防 rigged)
L5 学习层: 只校准先验不学策略(账本历史监督校准 P(refuted)/empirical Bayes 来源基率/
          bandit-BO 实验成本模型/GEPA 式 prompt 进化) — 端到端 RL 显式排除
          (可审计性是产品需求;样本昂贵;非平稳)
```

**对抗虚假信息的边界（诚实申报）**：高级洗白（付费投放声誉媒体/专家代笔）会穿透检测；缓解=make-or-break 独立根抽样溯源+金融类默认 primary-data-only+搜索信封披露污染。承诺不是"不会被骗"，是"被骗时能看见自己身处什么信息环境"。

## 方向策略：Thompson 采样（方向级组合管理）

- **方向来源封闭**（结构化生成）：用户假设账本候选、kill 图分支、被驳变体、幸存者邻接扩展。硬上限 8 臂，第 9 个进停车场。
- **臂价值后验**（四信号）：kill-存活率（被认真攻击过而不死）、证据产率（G3 同量）、决策杠杆（kill 图中心性）、意外度（对先验的 KL 散度）。
- **分配**：每轮从各臂价值后验采样，预算给采样最高者——不确定自然被探索、证实自然被利用，无手工 explore/exploit 规则。
- **触发器**：深挖=价值后验高且集中 ∨ make-or-break 悬在 ~0.5（便宜实验翻转全局）；增宽=全员 EVSI 跌破阈 ∨ 幸存者邻接 ∨ 高意外作废他向假设。**增宽预算结构性封顶 ≤30%**，发散靠预算结构防，不靠意志力防。
- **人界面**：轮边界呈现组合面板（方向×价值后验×下轮分配）；重大转向=计划重签。

## 偏航检测与恢复（三级）

| 级 | 检测 | 恢复 | 谁批 |
|---|---|---|---|
| 计划级（兔子洞/优先级漂移） | 预算-中心性会计：累计花费/中心性持续上升 | 重排 VOI 队列，孤儿线程进停车场 | **自动** |
| 问题级（问题过期/框架错误） | 问题新鲜度复检（每 K=5 轮或 make-or-break 落定触发：用当前知识重新结晶问题，与活跃计划 diff） | delta 报告（"真正该问的是 X"）→ 改道 | **人签**（问题变了=用户签过的东西变了） |
| 知识级 | 前提被驳 → kill_edges 传播 | 后代主张标 stale 重入验证 | **自动**（append-only，重开不删除） |

贯穿信号：决策相关性追踪（每个研究动作链回 kill 图承重主张）+ 信息产率衰减（连续数轮无 make-or-break 后验移动=空转）。
