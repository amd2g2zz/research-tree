# 用户旅程与体验规格 — research-tree v2.1

版本 v2.1 · 2026-10-28（v2.1：**页面逻辑定稿（原型验证回写）**——项目首页=应用默认落点；侧栏研究树三层导航（项目→任务→版本/草稿节点，可折叠细轨）；hub 对话=项目主界面（研究从对话发起、收敛自动回对话）；研究页=三层图谱（研究问题→主线任务→调研 DAG）+ console 同步重放；快照只读视图。删除 v2.0 的"三栏工作区"布局——被原型否决）

## 页面逻辑总纲（hub 模式）

- **项目首页（P0）是应用默认落点：首页 = 默认项目**。打开应用/重置/新建项目都落在默认项目的工作台概览。
- **侧栏研究树（常驻）是唯一导航器**：项目 → 任务 → 版本/草稿，三层可点。
- **对话是项目主界面（hub）**：研究从对话发起（分解确认）、结束后**自动回到对话**；报告/图谱/版本都是从对话进出的视图，没有"流程终点页"。
- 收敛与提交都以**对话内系统消息 + 任务状态卡**告知；用户的下一步动作永远在对话页可见。

## 页面清单（P0-P5）

### P0 项目首页（应用默认落点）
- **元素**：项目名+描述+附件 chips；三体征（研究线数 / 主分支最新版本+裁决+hash / 主线已用时间）；研究线列表（主线/支线 + 各自最新提交摘要）。
- **动作**：进入对话（主线任务）→ P2；查看最新报告 vN → 只读快照；版本管理 → P5。
- **规则**：侧栏文件夹点击、logo 点击均回首页；新建项目后落其首页；项目有提交后自动长出"查看最新报告"入口。

### P1 侧栏研究树（常驻，可折叠）
- **结构**：📁 项目（文件夹，可折叠）→ 任务（● 主分支·任务名 ／ ⑂ 支线（fork 自 vN），带状态点）→ 版本节点（vN·hash·裁决，最新在上）+ 草稿节点（"未冻结·不可跟踪"，仅运行/收敛时出现）。
- **动作**：点任务 → 对话页；点版本节点 → 只读快照报告；点草稿节点 → 研究页；＋新建项目。
- **规则**：默认展开当前项目；主线/支线在树中直接可辨；归档项目只读陈列于树底；折叠为细轨（项目圆点+新建），展开恢复。

### P2 对话页（hub 主界面）
- **元素**：消息流（用户/rt 路由回执/系统事件）、任务状态卡（运行中→查看研究；收敛→查看报告·管理产物+冻结提交；提交后消失）、输入框（贯穿所有阶段=追加信息门）、示例句（仅首轮）。
- **动作**：发送（逐句四分路由）；「聊得差不多了 → 分解」（≥3 句被路由后可用）；对齐卡（提交后）→ 继续研究（版本+1）。
- **出口**：P3（分解）/ P4（查看研究）。

### P3 分解页
- **目的**：把对话结构化为六要素，确认后开工。
- **元素**：六类要素卡（需求/条件约束/任务背景/用户意图/拒绝点/难点），每条带溯源引用（来自原句/附件）；kill 条件与预算说明。
- **动作**：删除要素条目（确认前，真按钮）；「返回对话」（保留已填内容，可续聊）；「确认无误，启动研究 vN」。
- **规则**：充分性 checklist——六类各 ≥1（拒绝点可显式为"无"）；要素集随版本落盘，确认后变更=重大转向重签。

### P4 研究页（从对话/侧栏/首页进出）
- **元素**：**三层图谱**（❓研究问题 → 🧵主线任务（task-id+版本+fork 血缘）→ 调研 DAG：阶段容器×主张行，开环/ROLLUP 徽章，阶段间依赖虚线）；Console 日志（终端式，随图谱重放同步滚动，点击行跳转主张）；重放条（拖动=回到该拍，图谱与日志同步）；主张抽屉（lineage 三层：节点→详情→原始 session/证据原文）；图例；滚轮缩放（锚定光标）+ 拖拽平移 + minimap。
- **动作**：推进一拍 / 自动（早终止时自动暂停）；早终止问询（make-or-break 被驳）：埋了 / 换变体 / 继续挖——问句不是判决；收敛后：报告+产物管理（删除节点→deleted_nodes）、冻结提交（摘要+hash+裁决四态）。
- **出口**：**研究收敛瞬间自动回到对话页（仅跳一次，事后可从研究树再进报告）**；冻结前后可自由往返，不销毁草稿。

### P5 版本页（从首页/对话页头/研究页头进入）
- **元素**：版本时间线（vN/hash/裁决/摘要，最新在上）、草稿行（若有，标注"未冻结·不可跟踪"）、分叉标记（⑂ 已分叉 → 支线）。
- **动作**：继续研究（版本+1）→ P2 对齐；回研究草稿（若有未冻结草稿，替代误触"+1"）；从此分叉 → 新 Task → P2；切换到支线。
- **规则**：主分支最新为默认展示；点击侧栏版本节点进入任意历史快照（只读）。

### 快照视图（只读，从侧栏版本节点/首页"最新报告"进入）
- 已冻结横幅（vN·hash·裁决——不可再修改；继续研究=版本+1）+ 该版本完整报告投影 + 「回当前工作区」。

## 六要素分解可视化（核心交互件）

**布局：分组卡片墙**（信息密度优先）——六格：🎯需求 / 📌条件约束（硬/猜测分列）/ 📖任务背景（含附件解析）/ 💡用户意图 / 🚫拒绝点 / ⚠难点→kill 候选。

**规则**：
1. **溯源律可见**：每张卡带溯源引用（"来自你的话：'…'"/"来自附件：xxx.xlsx"）；无法溯源的要素不落盘。
2. **编辑权在确认前**：每张卡可删（真按钮）；确认后要素集随 v0 冻结，变更=重大转向重签。
3. **难点↔主张对照**：难点卡逐条标注映射到的 kill 图承重主张。
4. **充分性 checklist**：六类各 ≥1（拒绝点可显式为"无"）；难点 ≥1 未映射 kill 候选=预注册缺口，阻止确认。
5. **非演示项目的脚手架**：要素不足时以"待对齐"占位卡如实呈现缺口，而不是拿演示内容冒充。

## 研究图谱（三层，信任面）

```
❓ 研究问题（顶层，唯一不变——一个项目一个研究主题）
   └ 分解为研究任务
🧵 主线任务（task-id · 版本数 · fork 血缘标注）
   └ 计划
▣ 调研 DAG —— 阶段容器（=kill 图因子簇）
     └ 主张行（状态着色+后验+KILL/GATE 徽章；开环 x/y / ROLLUP ✓）
        阶段间依赖虚线带标签
```

- 图例常驻（问题/任务/阶段/主张）；EVSI 饱和 / 预算尽 → 阶段 ROLLUP；全局 12h 硬帽。
- 任一结论 3 次点击内到达原始证据（抽屉→证据→sha256 原文）。

## 报告与底稿（同源双渲染）

**报告结构（叙事渲染，收敛后在研究页呈现）**：
1. 你的想法，被这样理解了（重述；错了你纠正，纠正也是数据）
2. 我们怎么验证的（方法透明：双席、分层、搜索信封）
3. 主张账本叙事（按权重排列：承重/门控/次要，各带后验与证据数）
4. 反证与让步（什么在反驳这个想法、什么顶住了攻击）
5. 信心与不确定性（档位非百分比；"什么证据会改变这个裁决"）
6. 最便宜的下一步（即使 GO，怎么用最小成本继续去险）
7. 三元裁决（证据说什么[无偏好] × 你的偏好与风险[你签的] → 建议）

**底稿结构（结构渲染 = 下游接口，schema 冻结）**：
```
clarified_question:   澄清后的问题与范围（含 non-goals）
supported_claims:     [{text, posterior, verify_tier, evidence_refs}]
unverified_assumptions: [{text, experiment_gated?, suggested_probe}]   ← 下游开工前必读
refuted_and_disposition: 被驳主张与处置（防下游重踩）
capability_outline:   从已证实主张推导（非承诺性规格）
constraints:          对话确认的（硬约束与猜测约束分列）
```

## 关键交互件

| 件 | 行为 |
|---|---|
| 回声确认 | 只对改变 kill 条件∨可行域菜单∨底稿结构的解构触发 |
| 组合面板 | 轮边界：方向×价值后验×下轮预算分配；重大转向=重签 |
| 早终止问询 | 呈现证据+"埋了/继续挖/换变体"三选；**问句不是判决**；埋了→收敛给 NO-GO 建议，最终裁决在冻结时 |
| 纠正受理 | 纠正按同一四分路由分解——系统无立场可让步，只有路由 |
| 后果映射 | 偏好变更照办，但可行域代价如实并排呈现 |
| 可行域菜单 | 不可达时：算术证明+可达点菜单+换轨提议——永不裸拒 |
| 任务状态卡 | 对话页常驻的推进器：阶段可见、下一步动作唯一化 |

## 产品红线（体验层）

永不输出无证据的"这不现实"；永不按用户画像改变任何行为；报告永远含反证章；单源/污染证据永不标"已证实"；PARK 必须带复活条件；底稿永远含 unverified_assumptions；**草稿永远明确标注"未冻结·不可跟踪"**；**已提交版本永不暗示可修改——一切"纠正历史"都引导为新版本**；**状态不裸靠颜色传达（始终伴随文字/图标）**。
