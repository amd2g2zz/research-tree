# RT-006: Finding Packs and Decision Ledger

## Status

Accepted for implementation. This specification is the executable scope for
GitHub issue #6 and consumes RT-005 Work Items.

## Public API

```python
finding = FindingPackCompiler(store).compile(
    round_id="round-001",
    finding_id="finding-isolation",
    work_item=work,
    observations=[...],
    option_effects=[...],
    implementation_implications=[...],
    remaining_uncertainties=[...],
)
decision = DecisionLedgerCompiler(store).converge(
    round_id="round-001",
    decision_id="decision-isolation",
    blueprint_target=target,
    decision_slot_id="slot-isolation",
    finding_packs=[finding],
    status="conditional",
    ...,
)
```

## Finding Pack Contract

```python
{
    "id": "finding-isolation",
    "work_item_id": "work-isolation",
    "decision_slot_id": "slot-isolation",
    "observations": [
        {
            "claim": "one atomic observed fact",
            "anchor": {"kind": "source|repository|input|experiment", "ref": "URL or path:symbol"},
            "applicability": "conditions and version scope",
            "confidence": "low|medium|high",
            "limitation": "what this does not establish",
        }
    ],
    "option_effects": [{"option": "candidate-a", "effect": "supports|contradicts|limits"}],
    "implementation_implications": ["concrete consequence"],
    "remaining_uncertainties": [],
}
```

A Finding Pack requires at least one atomic observation and at least one option
effect for an option on its exact Decision Slot. A bare source list cannot
match the contract.

## Decision Ledger Contract

```python
{
    "id": "decision-isolation",
    "round_id": "round-001",
    "decision_slot_id": "slot-isolation",
    "status": "selected|conditional|deferred|blocked",
    "selected_option": "candidate-a or null",
    "alternatives": [{"option": "candidate-b", "disposition": "rejected|deferred|unresolved", "reason": "..."}],
    "anchors": [{"kind": "finding|repository|input|experiment", "ref": "finding id or anchor"}],
    "design_consequence": "component/interface/state change",
    "repository_touchpoints": [{"path": "src/agent.py", "symbol": "run"}],
    "validation": {"kind": "test|spike|metric|review", "oracle": "observable pass condition"},
    "change_tasks": [
        {"id": "change-isolation", "description": "...", "acceptance_oracle": "...", "repository_touchpoints": []}
    ],
    "assumptions": [],
    "fallback": "safe behavior when condition fails",
    "reversal_condition": "new evidence that changes this choice",
    "revision_reason": "why this ledger revision exists",
}
```

P0 `selected` and `conditional` decisions must use at least one supplied
Finding Pack anchor and have a nonempty design consequence, change task, and
validation oracle. `deferred` and `blocked` decisions may lack findings but
must retain a nonempty fallback. Every decision needs an alternative and a
reversal condition.

## Test-First Acceptance Cases

| Case | Expected result |
| --- | --- |
| atomic finding | exact work/target parent lineage; source list alone is rejected |
| conflicting evidence | support and contradiction remain distinct finding artifacts under a conditional decision |
| P0 trace | missing alternative, finding anchor, change task, fallback, or reversal condition fails before append |
| revision history | revised choice appends a new decision revision that references the old one and retains prior evidence |
