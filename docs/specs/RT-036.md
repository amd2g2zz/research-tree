# RT-036: Runtime Discoverability and First Use

## Status

Accepted for implementation. This specification is the product-facing scope
for GitHub issue #36.

## Scope

The repository ships a Python runtime for persisted research-round artifacts
and their composed workflow services. It does not ship a CLI that runs the
complete research workflow or makes autonomous research decisions.

The supported CLI boundary is round management only: create a round and
reconstruct an existing round from an explicit run-store root. The supported
route for the composed workflow is the public `research_tree` Python API,
which exports `RunStore` and the intake, intent, brief, blueprint, decision,
delivery, readiness, feedback, and export services.

## First-Use Contract

README must provide copyable commands to:

1. install the project with `uv sync`;
2. create a first round using an explicit store root;
3. recover/read back that exact round using the same store root; and
4. discover the CLI's scope with `--help`.

The CLI help must explicitly state that it is round-management only and point
users to the `research_tree` Python API for composed workflows.

## Acceptance Tests

| Scenario | Expected result |
| --- | --- |
| Documented first-use create command | creates the requested round in the explicit store |
| Documented recovery/readback command | reconstructs that round from the same store root |
| CLI help | names the round-management-only boundary and public Python route |
| README guard | keeps installation, create, recovery, scope, and public API guidance discoverable |
