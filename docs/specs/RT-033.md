# RT-033: Stored Lineage Reference Integrity

## Status

Accepted for implementation. This specification is the executable scope for
GitHub issue #33.

## Problem

Individual persisted envelopes can be valid while their references point to
artifact revisions that were deleted or were never stored. A reconstructed
round must not expose that partially replayable state.

## Load Contract

`RunStore.load_round(round_id)` returns a snapshot only after every persisted
artifact parent reference and every `artifact-appended` event reference has
resolved to an exact stored artifact revision. Parent references may target the
round being loaded or another round in the same store.

Any unresolved reference, including an absent target round or revision, raises
`DataIntegrityError`. The loader must not return a partial `RoundSnapshot`, and
it must not expose `ArtifactNotFoundError` as a load-time corruption result.

Other event kinds do not require an `artifact_ref`; only a present
`artifact-appended` reference is checked by this specification.

## Test-First Acceptance Cases

| Corruption | Expected load result |
| --- | --- |
| Same-round artifact parent revision deleted | `DataIntegrityError` |
| Cross-round artifact parent revision deleted | `DataIntegrityError` |
| `artifact-appended` event references absent revision | `DataIntegrityError` |
