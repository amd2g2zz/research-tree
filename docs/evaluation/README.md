# Evaluation Documentation

This directory routes to current, reviewable evaluation design material. It is
separate from raw runs, sealed holdouts, credentials, and other evaluator-owned
data.

- [Issue #268 research records](research/) — the comprehensive evaluation
  design, Technical Research Package, and Human Research Report.
- [Evaluation asset governance](../governance/evaluation-assets.md) — retained
  asset classes, validation command, and data boundaries.
- [`evaluation/` repository namespace](../../evaluation/) — versioned public
  cases, schemas, harnesses, fixtures, baselines, and redacted results.

Evaluation material reports evidence under its stated revision and conditions.
It does not silently change product behavior or establish a release decision.
