# Governance Documentation

Governance documents define how to classify and maintain documentation and
evaluation material. They are for maintainers, reviewers, evaluators, and
agents making source-of-truth decisions.

- [Documentation authority](documentation-authority.md) — precedence,
  lifecycle, canonical edit locations, and terminology rules.
- [Evaluation asset governance](evaluation-assets.md) — what can be tracked,
  what remains evaluator-owned, and the public validation boundary.

Read [Evaluation documentation](../evaluation/README.md) for the active
evaluation materials themselves, and [History](../history/README.md) before
using a revision-bound record as evidence.
