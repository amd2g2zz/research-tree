# Historical Documentation

These records are preserved for traceability, audit, and revision-specific
context. They are not entry points for current behavior or implementation
authority.

- [Historical specifications](../specs/) — earlier requirement and delivery
  contracts, superseded by the current [Product specification](../../PRODUCT.md).
- [Historical reviews](../reviews/) — prior audit and acceptance records.
- [Consolidated requirements notes](../需求理解.md) — preserved early context.
- [Consolidated design notes](../方案设计.md) — preserved early design context.

The files stay at these stable paths because existing OpenSpec and review
records may cite them. When a claim affects current work, validate it against
the product contract, an ADR, an active OpenSpec change, code, tests, or a
reachable receipt.
