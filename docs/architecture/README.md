# Architecture Documentation

Accepted architecture decisions are retained in the stable
[ADR collection](../adr/). Read the relevant ADR after the product contract,
not as a substitute for it.

| Question | Authority |
| --- | --- |
| What behavior is currently accepted? | [Product specification](../../PRODUCT.md) |
| Why does an accepted architecture boundary exist? | [Architecture decision records](../adr/) |
| What is planned but not yet accepted? | Selected active [OpenSpec change](../../openspec/changes/) |

Historical specifications and reviews may explain how a decision evolved, but
they never supersede the current product contract or ADR collection.
